# 页面框架

当前阶段优先保证页面关系、导航与共享组件稳定，具体业务功能随后逐页接入。

```text
四个主页面（可横滑）
├── 流水
│   ├── 搜索与筛选（骨架）
│   └── 账单详情
│       └── 编辑账单（骨架）
├── 日历
│   ├── 选中日流水（共享列表）
│   └── 当日流水独立页（骨架）
├── 统计
└── 账户
    ├── 账户详情（骨架）
    ├── 分类管理
    └── 数据管理（骨架）

全局
├── 新增记账
├── 设置（骨架）
└── 临时选择与确认层
```

所有完整页面统一进入 `LedgerNavigationState.pageStack`，临时选择器与确认框统一进入
`modal`。返回顺序为 `modal → pageStack → 退出应用`，页面不得自行保存另一套可见页面状态。

## 共享流水系统

`TransactionListItem` 是唯一单条流水组件；`TransactionList` 是唯一平铺流水列表。
流水首页、日历选中日，以及未来的搜索结果、账户详情和分类明细都必须复用它们。
页面只决定数据来源和分组标题，不得重新实现金额、颜色、时间或点击规则。

## 骨架页原则

骨架页不是假功能，而是已进入正式导航图、具备参数和返回路径但尚未接入业务数据的页面。
实现功能时替换骨架内容，不改变它的页面身份和上游入口。
