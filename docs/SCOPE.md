# 产品范围

## 我们真正要解决的问题

从现有账单导出的实际使用情况看，高频数据集中在日期、收支、金额、两级分类和账户。备注、标签偶尔使用；退款、报销、多币种和附件目前没有形成真实需求。

因此第一版只围绕三个动作设计：

1. 快速记一笔；
2. 随时找回并修改；
3. 一眼看懂这个月的钱去了哪里。

## V1 必须有

- 支出、收入、转账三种交易；
- 金额、时间、一级/二级分类、账户、备注、标签；
- 账户及余额调整；
- 日列表、月视图、搜索和筛选；
- 月预算与预算进度；
- 月度趋势、分类占比、收支对比；
- 从现有账单表格导入，导入前预览并检查重复；
- 本地备份、恢复和通用格式导出；
- 完整离线工作；
- 1×1 快速记账组件与月度概览组件。

## V1.5 再评估

- 多账本；
- 周期账单；
- 对账；
- 分类预算；
- 附件；
- 生物识别锁；
- 更丰富的桌面组件；
- 多币种。

这些能力必须作为可选模块接入，不能污染 V1 的核心记账路径。

## 暂不开发

- 会员、广告、社区和积分；
- 自建云账户体系；
- 股票、基金实时行情；
- 短信、通知、OCR 自动记账；
- 语音记账；
- 心愿单、债务催收和报销工作流；
- 农历、复杂日历和与记账无关的工具集合。

暂不开发不等于永远拒绝，而是没有真实使用证据前不把复杂度带进核心。

## 验收标准

- 冷启动后可以在 10 秒内记完一笔常用支出；
- 所有金额使用整数最小货币单位存储，不使用浮点数；
- 导入失败不会写入半份数据；
- 同一份导入文件重复执行时能识别重复记录；
- 删除、修改和导入都有可恢复路径；
- 没有网络权限时，核心功能不受影响。
