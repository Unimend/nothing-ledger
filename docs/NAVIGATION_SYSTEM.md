# 导航系统

项目只允许三类可见状态，各自拥有唯一入口，不得相互代替。

## 一、开发外壳导航

`RootNavigationState + RootNavigationReducer` 只负责：

```text
组件实验室 ⇄ 产品预览
```

它不理解账单、账户或产品页面。

## 二、产品页面导航

`LedgerNavigationState + LedgerNavigationReducer` 是正式产品唯一页面导航系统：

```text
selectedMain  四个主页面
pageStack     搜索、详情、编辑、管理等完整页面
modal         账户选择、分类选择、日期选择和确认框
```

所有产品入口只发送 `LedgerNavigationAction`。页面不得新增可空 ID、布尔值或第二个页面枚举来决定当前显示哪个完整页面。

## 三、组件局部状态

组件可以拥有不会改变页面身份的局部状态，例如：

- 日期选择器展开或收起；
- 当前编辑文本；
- 实验室聚焦查看某一分区；
- 点击计数与动画进度。

局部状态不得打开另一个完整产品页面，也不得保存产品页面返回路径。需要跨页面或需要系统返回键处理时，必须升级为产品导航目的地或模态目的地。

## 返回顺序

```text
产品临时弹层 → 产品页面栈 → 组件实验室 → 退出应用
```

业务组件只上报事件，例如 `onTransactionClick(transaction)`；它们不能直接选择目标页面。目标由装配该组件的页面转换为统一导航动作。
