# 一木记账交互参考

本文件只记录交互结构与取舍，不复制一木记账的代码、素材或视觉资产。

## 已核对的核心路径

### 首页

- 顶部先展示本月收入、支出、结余与预算；
- “添加一条新记账”是首页最明确的主操作；
- 下方直接按日期展示流水，每日同时给出收入、支出合计；
- 底部导航再进入日历、资产、统计和设置。

这说明首页的任务不是同时编辑所有资料，而是“看本月 → 记一笔 → 找到旧记录”。

### 新增账单

- 收入、支出、转账在顶部切换；
- 分类占据主要选择区域，强调高频分类；
- 日期、账户、报销、附件、优惠等附加信息压缩在金额上方的一行；
- 金额与备注靠近键盘；
- 数字键盘固定在底部，`1`、`2`、`3` 直接得到 `123` 元，小数点才输入角分；
- 完成按钮与键盘处在同一操作区，不需要滚动寻找。

## Nothing Ledger 应采用的原则

1. 流水页承担首页职责：月度摘要、添加入口、按日流水。
2. 记账页是独立、短路径的编辑界面，不显示账户和分类管理功能。
3. 分类优先显示常用项；账户、日期、备注收束成紧凑详情栏。
4. 金额按“元”直接输入，最多保留两位小数，全程仍以整数分保存。
5. 键盘和完成操作保持在稳定位置，不因数据刷新跳动。
6. 所有按键反馈由 Nothing 动效系统统一提供，不使用系统泛白涟漪。

## 不照搬的部分

- 不加入债务、报销、附件、优惠、定位等当前没有真实需求的入口；
- 不复制一木记账的图标、配色、卡片造型和分类素材；
- 不让大量低频功能挤占快速记账路径；
- 不引入会员、广告或联网依赖。

## 下一轮页面顺序

1. 将“流水”升级为默认首页，并放置清晰的“记一笔”入口；
2. 将记账编辑改成独立页面，保留收支类型、分类、账户、金额和备注；
3. 账户成为独立主页面，分类维护作为账户页的二级入口；
4. 日历按天展示收支并下钻当天流水；
5. 统计先展示月度结论与每日趋势，再逐步补充分类分析；
6. 流水详情先解析可读账户和分类名称，再接入修改、删除和撤回。
