# NOTHING LEDGER

> A local-first Android ledger with a quiet Nothing-inspired interface.

Nothing Ledger 是一个从零开始构建的 Android 记账应用。它不会复刻现有产品，也不会复制其他开源项目的代码；我们只研究成熟项目解决问题的方式，再为自己的使用习惯重新设计。

第一目标不是“功能最多”，而是：

- 三步以内记完一笔；
- 数据始终属于用户，离线也能完整使用；
- 账目、账户和分类可靠且可追溯；
- 统计足够清楚，但不制造信息噪音；
- Nothing 风格不是皮肤，而是一套统一的视觉、动效和交互规则。

## 核心原则

```text
界面只表达状态与意图
        ↓
用例决定一次操作该做什么
        ↓
领域系统维护记账规则
        ↓
仓库接口隔离数据来源
        ↓
本地数据库保存唯一可信数据
```

任何一个系统都不直接修改另一个系统的内部状态。系统之间只通过明确的数据模型、命令和事件沟通。

## 隐私

仓库不会包含真实账单、数据库、备份、附件、密钥或本机配置。个人数据文件已经由 `.gitignore` 主动排除。
